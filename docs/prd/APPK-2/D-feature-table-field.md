**写法约定**：“整行”= 该表附表 A 中的全部列。列清单出现“指定列”时，是从 PHP 源码中该写入点附近出现的该表字段取并集所得（宁多勿少），可由 `php/application` 下对应控制器/模型的更新语句复核。读取默认也是整行（ThinkPHP `select *`），只有注明字段的才限于所列字段。所有写入只做 `INSERT/UPDATE/DELETE`，不含 DDL（BR-1）。
