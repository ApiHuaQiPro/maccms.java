自动化通道取值（**每条用例只能取一个值**）：`UI`（`tests/e2e/APPK-2/`，写法见 `multica-test-t3-ui-automation`）、`接口`（`tests/api/APPK-2/`，写法见 `multica-test-t3-api-automation`）、`手工`（对照报告、DB 快照等一次性验收动作，产物落 `docs/test/APPK-2/`）。

- 同一用例需要多条通道时**拆用例**（编号各自独立），不写「UI + 接口」「手工 + 回归单测」。
- 「回归单测」不是本 skill 规定的执行通道：`./mvnw verify` 等单测/集成测试属开发者的 G2 证据，由智能调度在 G2 提供；本期只作为 T3 的**前置**（未提供 → 相关用例 BLOCKED），不作为 T3 执行通道。
- `手工` 通道的用例在 T3 按编排 skill 记 BLOCKED（需人工验证），交智能调度安排人工。
