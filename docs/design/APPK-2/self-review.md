## 逐条看图自评

- [x] **间距只用 4px 刻度，节奏统一，无随手像素。** 依据：三档截图的卡片均使用 p-4/6、gap-2/3/4/6/8、mt-1/2/3/4/6；`shot-1280.png` 各 section 间距一致，`shot-390.png` 保持相同节奏。海报圆角、阴影等 token 见 HTML 注释和 Tailwind config。线框中 `aspect-[3/4]` 是比例不是任意间距。
- [x] **字号阶梯一致，层级清楚。** 依据：`shot-1280.png` 顶部 4xl 主标题、各卡 xl/2xl 标题、sm 正文、xs 辅助说明；`shot-390.png` 主标题降为 2xl，正文和标签层级仍清晰。
- [x] **颜色来自 token，语义正确。** 依据：HTML Tailwind config 固定 brand/ink/muted/line/surface/danger/warning/success；三档图中蓝色用于主信息、红色用于错误/缺失、橙色用于无权限、绿色用于正确 URL，深色仅用于页首和路由总结。
- [x] **六态齐全且每态信息完整。** 依据：三档截图“状态必须保持 PHP 语义”区同时可见正常（D-01/D-02）、加载（D-03）、空（D-04）、错误（D-05）、禁用（D-06）、无权限（D-07）；另有模板缺失 D-11。每态都有表现和禁止回退/新增 UI 的说明。
- [x] **交互态有静态变体。** 依据：三档截图“悬停、焦点、校验”区分别展示 D-08 深蓝悬停、D-09 双层可见焦点、D-10 红边输入与安全错误文案。
- [x] **三档响应式不塌版、无横向滚动。** 依据：`shot-390.png` 单列、卡片内容未裁切；`shot-768.png` 桌面拓扑四列，其余按两列/三列重排；`shot-1280.png` 内容居中且两侧留白均衡。长 URL 在手机截图内换行，没有溢出卡片。
- [x] **自动对比度 0 违规；焦点可见；可点区域 ≥40px。** 依据：上方脚本输出；D-09 的焦点框在 three shots 中清晰可见；D-08/D-09 示例链接与 D-06 按钮均 min-h-10（40px）。该勾选仅指本设计稿；官方模板现状没有被宣称为 AA 或 40px 全部合规。
- [x] **真实文案、无占位、不泄露敏感信息。** 依据：三档图没有 lorem/“待定”占位；“示例影片 A～D”明确是拓扑示例数据，无真实公司或个人信息；D-10 统一“账号或密码错误”，没有账号存在性提示。
- [x] **整体观感：对齐、留白、视觉层级无明显审美问题。** 依据：`shot-1280.png` 主内容最大宽度一致、卡片网格对齐、状态区 3×2 平衡；`shot-768.png` 与 `shot-390.png` 重排后标题、正文和标签均未重叠。
