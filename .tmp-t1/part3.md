#### TC-F-PAGE-006 `/template/**` 静态资源边界（OP-T5=a，SEC-7 白名单）

- 覆盖维度：正常、边界、安全
- 优先级：P1
- 追溯 AC-5（页面可用性）、技术设计 C-43/C-44/V-18
- 自动化通道：接口
- 前置：站点根存在 `template/default_pc/`；已知一份存在的 `css/*.css`、`js/*.js`、`images/*.png`、`ads/*`
- 步骤与预期：
  1. `GET /template/default_pc/css/<存在的文件>.css` → 200，`Content-Type` 与 §6.10 固定表一致，内容字节与原文件相同。
  2. `GET /template/default_pc/images/<存在的图片>` → 200，`Content-Type` 正确。
  3. `HEAD` 请求 → 200 且无响应体。
  4. 带 `If-Modified-Since` 的重复请求 → 304（`Last-Modified` 条件请求）。
  5. `GET /template/default_pc/html/index.html` → 404（子目录不在白名单）。
  6. `GET /template/default_pc/index.ini`、`GET /template/default_pc/js/x.php` → 404。
  7. `GET /template/default_pc/css/../html/index.html`、含 `%2e%2e`、含 `%00`、含反斜杠或 `:` 的路径 → 404，响应体不回显路径。
  8. 指向 `template/` 之外的符号链接文件 → 404（NOFOLLOW + 规范化后须在 `template/` 内）。
  9. 断言拒绝时日志为 `DEBUG` `asset_denied reason=<FileException 原因>`，不含路径（SUG-2） → 符合。
