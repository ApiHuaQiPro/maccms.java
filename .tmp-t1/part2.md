### 2.1 FR-1 模板包来源与放置（AC-1）

- 覆盖维度：正常
- 优先级：P1
- 追溯 AC-1
- 自动化通道：手工
- 前置：模板包已按 OP-15/技术设计 DEC-1 放入 `third_party/maccms-template-v2020.1000.1035/`；`git` 可用；PRE- 不依赖
- 步骤与预期：
  1. 对模板包目录下每个文件执行 `git hash-object <file>` → 每个文件 SHA-1 与 PRD 附表 E.3 逐条一致。
  2. 统计 `default_pc` 与 `default_wap` 的文件数 → 分别为 147 与 127，合计 274。
  3. 检查 `default_wap` 下是否有 `ads/` 目录 → 没有。
  4. 检查 `.gitattributes` 中模板包按字节检出的规则存在 → 存在（技术设计 C-1～C-5）；工作区文件不含 `\r` 转换导致的哈希偏差（与 INS-1 同类问题）。

#### TC-F-TPL-003 模板目录配置为不存在目录时的表现
- 模块：模板包
- 覆盖维度：异常、页面状态
- 优先级：P1
- 追溯 AC-1

#### TC-F-SYN-004 输出上限与循环上限（拒绝服务边界）

- 优先级：P2
- 追溯 AC-2
- 自动化通道：手工（配置 + 接口）
- 前置：`maccms.phptemplate.limits.loop-count`、`limits.output-bytes`、`limits.depth` 已配置为可触发的小值（测试环境）
- 步骤与预期：
  1. 渲染一个超过 `loop-count` 的循环模板 → 渲染失败并给出明确错误（不挂起进程、不 OOM）。
  2. 渲染一个超过 `output-bytes` 的模板 → 渲染失败；响应不是「200 + 半页」（缓冲语义，技术设计 C-70）。

  4. 断言三次失败后进程仍可正常响应其他页面 → 后续请求 200。
